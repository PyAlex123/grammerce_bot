# Grammerce Bot — редизайн под mobile-first

Сводный документ по итогам разбора. Цель: сделать бота-воронку **понятным, привлекательным и максимально простым** — одна главная кнопка вместо развилок, минимум лишнего, плюс «живые» уведомления. Бот двуязычный (ru/uz), поэтому все тексты даны на обоих языках.

---

## 1. Анализ трёх ботов

### Grammerce (текущий)
**Плюсы:** чисто; reply-клавиатура всегда под рукой; ниши для демо (Одежда/Цветы/Косметика/Электроника) — релевантнее, чем общий «демо» у конкурентов.
**Минусы:**
- Приветствие пустое («Главное меню 👇») — нет ценности и крючка.
- «Создать магазин» разветвляется на «Зарегистрироваться» vs «Войти через Telegram» — для холодного лида выбор без разницы, тормозит конверсию.
- В чат утекает сырой URL `…/api/auth/telegram/consume?token=…` — выглядит как баг и небезопасно.
- FAQ с жаргоном (Setup Fee, API) — массовому лиду не нужен.

### Qlay (эталон по структуре)
**Забрать:** герой-картинка + описание бота (через BotFather, до `/start`); персональное приветствие по имени; **одна главная кнопка-WebApp** («Открыть») без развилок; демо/«узнать больше»/поддержка — просто текстовые ссылки; **жизненный цикл** — уведомления о заказах, нудж «у вас 1–2 товара, добавьте ещё», ре-энгейджмент. Mini App с нижней навигацией Товары/Заказы и кнопкой «+».
**Минус:** нет выбора ниши-демо — у Grammerce это сильнее.

### TGShop
**Забрать:** соцдоказательство (реальные витрины «что продают», «бренды уже создали»); чёткие «3 шага».
**Минус:** перегруз баннерами и текстом; вход по внешней ссылке с уходом в браузер.

> Замечание: рекламный креатив «Telegrad / реклама в Telegram 900 000 сум» — это не TGShop, а пример Telegram Ads. К дизайну бота не относится, пригодится для продвижения.

## 2. Вердикт

**Лучший вариант = скелет Qlay + ниши-демо Grammerce + лёгкое соцдоказательство TGShop − все развилки и утечка URL.**

Две ключевые фишки, которые надо взять обязательно:
1. **Одна WebApp-кнопка** «Создать магазин» вместо развилки регистрация/вход.
2. **Уведомления жизненного цикла** — именно они делают бота «живым».

---

## 3. Рекомендованная структура

Первый экран — один крючок, одна главная кнопка, два второстепенных действия:

- 🏪 **Создать магазин** — главная кнопка, WebApp, открывает кабинет уже залогиненным (вход по Telegram `initData`, без пароля).
- 👀 **Демо** и 💬 **Поддержка** — маленькие второстепенные кнопки.
- Постоянная **menu-кнопка** слева от поля ввода = WebApp «Кабинет».

Демо: «Демо» → выбор ниши → ссылка на демо-бот (сохраняем как преимущество).
Поддержка: короткий FAQ (Цена / Сроки / Оператор), без жаргона.

---

## 4. Что убрать

- Развилку «Зарегистрироваться» / «Войти через Telegram» → одна WebApp-кнопка. Сайт — мелкой текстовой ссылкой «открыть на компьютере».
- Утечку `consume?token=…` в чат → авторизация прозрачно внутри WebApp.
- Reply-клавиатуру из 3 кнопок как главный экран → главное действие одно.
- Жаргон в FAQ (Setup Fee, API) → Setup Fee сложить в ответ про цену; API — только через оператора.
- Экран выбора языка как блокер → автоопределение по Telegram + переключатель 🇷🇺/🇺🇿.

## 5. Что добавить

- Герой-картинку + описание бота в BotFather (видно до `/start`).
- Уведомления жизненного цикла через вебхук платформы (`user-registered` и новые события): «магазин почти готов», «новый заказ», ре-энгейджмент.
- Лёгкое соцдоказательство — пара витрин «сделано на Grammerce».

## 6. Готовые тексты

- UZ: `2 daqiqada Telegram'da do'kon. 0% komissiya.`

**«Что умеет этот бот» / описание**

### 6.3. Демо

**RU:** `Выберите нишу — откроем демо-магазин:`

После выбора: `Открываем демо 👇` + кнопка-ссылка на демо-бот.

**UZ:** `Sohani tanlang — demo-do'konni ochamiz:`

Tanlovdan keyin: `Demoni ochyapmiz 👇` + demo-botga havola tugmasi.

### 6.4. Поддержка / FAQ

**RU:** `Чем помочь? Выберите вопрос или напишите оператору:`
Кнопки: `💰 Сколько стоит?` · `⏱ Сроки запуска` · `👤 Живой оператор`

- Цена: `Подписка от 390 000 сум/мес: Start 390 000 · Business 650 000 · Premium 910 000. Все тарифы — 7 дней бесплатно. Отдельно, разово — подключение: дизайн магазина, загрузка товаров, настройка оплаты, обучение. Комиссии с продаж — 0%. Подробнее: grammerce.io`
- Сроки: `Запуск за 1–2 дня: вы оставляете заявку, мы собираем магазин и обучаем сотрудника. Дальше он работает 24/7.`
- Оператор: `Напишите ваш вопрос — оператор ответит в ближайшее время. Одно сообщение = один тикет.`

**UZ:** `Qanday yordam beramiz? Savolni tanlang yoki operatorga yozing:`
Tugmalar: `💰 Narxi qancha?` · `⏱ Ishga tushirish muddati` · `👤 Jonli operator`

- Narx: `Obuna oyiga 390 000 so'mdan: Start 390 000 · Business 650 000 · Premium 910 000. Barcha tariflar — 7 kun bepul. Alohida, bir martalik — ulanish: do'kon dizayni, tovarlarni yuklash, to'lovni sozlash, o'qitish. Savdodan komissiya — 0%. Batafsil: grammerce.io`
- Muddat: `Ishga tushirish 1–2 kunda: siz ariza qoldirasiz, biz do'konni yig'amiz va xodimni o'qitamiz. Keyin u 24/7 ishlaydi.`
- Operator: `Savolingizni yozing — operator tez orada javob beradi. Bitta xabar = bitta tiket.`

### 6.5. Уведомления жизненного цикла

**1. Магазин создан (после регистрации)**
- RU: `🎉 Магазин создан! Осталось добавить товары. Откройте кабинет и загрузите первые позиции — это пара минут.` + кнопка WebApp `Открыть кабинет`
- UZ: `🎉 Do'kon yaratildi! Endi tovar qo'shish qoldi. Kabinetni oching va birinchi tovarlarni yuklang — bir necha daqiqa.` + `Kabinetni ochish`

**2. Новый заказ**
- RU: `🛒 Новый заказ №{n}! Покупатель: {имя}, {телефон}. Сумма: {сумма}. Откройте, чтобы подтвердить.` + кнопка `Открыть заказ`
- UZ: `🛒 Yangi buyurtma №{n}! Xaridor: {ism}, {telefon}. Summa: {summa}. Tasdiqlash uchun oching.` + `Buyurtmani ochish`

**3. Ре-энгейджмент (через 2–3 дня, мало товаров)**
- RU: `В вашем магазине {n} товара. Добавьте больше — покупателям будет проще выбрать. Нужна помощь — напишите оператору.` + кнопка WebApp `Добавить товары`
- UZ: `Do'koningizda {n} ta tovar bor. Ko'proq qo'shing — xaridorlarga tanlash osonroq bo'ladi. Yordam kerak bo'lsa — operatorga yozing.` + `Tovar qo'shish`

## 7. UX-спецификация (для разработчика)

| Элемент | Решение |
|--------|---------|
| Главная кнопка | Одна, WebApp `Создать магазин` → кабинет, авто-вход по `initData` |
| Второстепенные | `Демо`, `Поддержка` — маленькие inline-кнопки |
| Menu-кнопка | WebApp `Кабинет` (слева от поля ввода) |
| Развилка регистр./вход | Убрать полностью |
| `consume_url` в чате | Не показывать; авторизация внутри WebApp |
| Reply-клавиатура из 3 | Убрать как главный экран |
| Язык | Автоопределение + переключатель 🇷🇺/🇺🇿, не блокер |
| FAQ | Цена / Сроки / Оператор; Setup Fee и API убрать с верхнего уровня |
| Уведомления | `user-registered` + новые события платформы → сообщения в бот |

### Привязка к коду
- `start.py` — новое приветствие, автоязык + переключатель, одна WebApp-кнопка.
- `register.py` — заменить две CTA (`Зарегистрироваться`/`Войти через Telegram`) на одну WebApp-кнопку; убрать показ `consume_url`.
- `demo.py` — без изменений (ниши оставляем).
- `support.py` — урезать FAQ до 3 пунктов, Setup Fee сложить в ответ про цену.
- `web.py` — расширить вебхук платформы на события «магазин создан / новый заказ / мало товаров» для уведомлений.
- BotFather — герой-картинка, короткое описание, «что умеет бот», menu-кнопка.

## 8. Порядок внедрения

1. BotFather: картинка + описания + menu-кнопка (быстро, без кода).
2. `start.py` + `register.py`: новое приветствие, одна WebApp-кнопка, убрать развилку и URL.
3. `support.py`: урезать FAQ.
4. `web.py`: уведомления жизненного цикла (магазин создан → новый заказ → ре-энгейджмент).
5. Лёгкое соцдоказательство (пара витрин «сделано на Grammerce»).

**TL;DR:** один крючок + одна WebApp-кнопка + живые уведомления. Ниши-демо — твоё преимущество, сохраняем; всё остальное упрощаем.
