# Grammerce Bot — Общее описание

## Что это такое

**Grammerce Bot** — это Telegram-бот для лидогенерации и продаж SaaS-платформы
**Grammerce** (конструктор онлайн-магазинов для предпринимателей Узбекистана).

Бот — это «входная воронка»: он встречает пользователя, рассказывает о продукте,
показывает живые демо-магазины, отвечает на частые вопросы, соединяет с живым
оператором и доводит заинтересованного пользователя до регистрации на платформе
`grammerce.io`.

Бот **двуязычный** — русский (`ru`) и узбекский (`uz`).

---

## Зачем он нужен (бизнес-цель)

1. **Привлечь** трафик из рекламы (Telegram Ads и др.) и не потерять его.
2. **Прогреть** пользователя: показать, как выглядит готовый магазин (демо), снять
   возражения через FAQ (цена, сроки, Setup Fee, API).
3. **Конвертировать** — выдать персональную ссылку для входа/регистрации на
   платформе.
4. **Не упустить тёплого клиента** — дать возможность поговорить с живым оператором
   прямо в Telegram.
5. **Собрать аналитику** — каждое действие пользователя пишется в базу (UTM-метки,
   просмотры демо, тикеты, события воронки), чтобы измерять эффективность рекламы.

## Как пользователь взаимодействует с ботом (сценарии)

### 1. Первый запуск `/start`
- Пользователь приходит по ссылке (часто с UTM-меткой из рекламы, например
  `/start utm_tgads_uzb4ru`).
- Бот создаёт запись о пользователе в базе, сохраняет UTM-метку (только при первом
  запуске, не перезаписывается).
- Если язык ещё не выбран — предлагает выбрать **русский / узбекский**.
- После выбора языка показывает приветствие и **главное меню** из трёх кнопок:
  - 🏪 Создать магазин
  - 👀 Смотреть демо
  - 💬 Поддержка

Если пользователь уже знаком боту (язык выбран ранее) — шаг с выбором языка
пропускается, сразу показывается меню.

### 2. Просмотр демо («Смотреть демо»)
- Бот предлагает выбрать **нишу**: Одежда, Цветы, Косметика, Электроника
  (Кофейня и Доставка еды временно отключены — демо-боты ещё не готовы).
- При выборе ниши бот логирует просмотр и даёт ссылку-кнопку на реальный
  демо-магазин-бот (например, `@grammerce_clothes_bot`).
- Кнопка «Назад» возвращает к списку ниш.

### 3. Регистрация / создание магазина («Создать магазин»)
- Бот обращается к **бэкенду платформы** (HTTP-запрос на
  `/api/auth/telegram/issue`), передавая данные Telegram-пользователя и секретный
  ключ бота.
- Платформа возвращает **одноразовую ссылку входа** (`consume_url`).
- Бот показывает две кнопки:
  - 📝 **Зарегистрироваться** → обычная регистрация на `grammerce.io/login`
  - ✅ **Войти через Telegram** → одноразовая авторизационная ссылка (вход без
    пароля прямо по Telegram-аккаунту).
- Если платформа недоступна — пользователь видит мягкое сообщение об ошибке, а
  событие пишется в лог.

Этот же сценарий можно вызвать прямой ссылкой `/start register`.

### Уведомление админу о новой регистрации
- Когда пользователь **впервые** входит/регистрирует магазин на платформе, платформа
  делает обратный вызов в бот (webhook `POST /api/bot/user-registered`, тот же
  секрет `X-Bot-Secret`).
- Бот шлёт админу (`SUPPORT_CHAT_ID`) сообщение «🎉 Новая регистрация на платформе!»
  с **именем**, **UTM-источником** (берётся из базы бота по `telegram_id`) и
  **временем**.
- Уведомление приходит **один раз** на пользователя — повторные вызовы платформы
  отсекаются по полю `registered_at` (идемпотентность).
- Это задел под будущий показ «статуса оплаты» пользователя.

### 4. Поддержка и FAQ («Поддержка»)
- Бот показывает кнопки с частыми вопросами:
  - 💰 Сколько стоит?
  - 🛠 Setup Fee
  - ⏱ Сроки запуска
  - 🔌 Есть ли API?
  - 👤 Живой оператор
- На FAQ-вопросы бот отвечает заранее заготовленным текстом.
- При нажатии «Живой оператор» бот переводит пользователя в режим ожидания вопроса:
  следующее сообщение становится **тикетом**.

### 5. Тикет и живой чат с оператором
- Пользователь пишет вопрос → бот сохраняет **тикет** в базу и **пересылает его в
  чат поддержки** (личный чат администратора) с кнопкой «Начать чат с пользователем».
- Администратор нажимает кнопку → запускается **двусторонний живой чат**:
  - сообщения оператора пересылаются пользователю (с префиксом «👤 Оператор:»);
  - сообщения пользователя пересылаются оператору (с префиксом «👤 @username:»).
- Оператор нажимает «🔴 Завершить чат» → диалог закрывается, обе стороны получают
  уведомление.
- Если оператор переключается на другого пользователя — предыдущая сессия тихо
  закрывается.

## С чем взаимодействует бот (внешние связи)

```
                    ┌─────────────────────────┐
   Пользователь ───►│                         │
   (Telegram)       │     Grammerce Bot       │◄──► PostgreSQL
                    │     (aiogram, Python)   │     (пользователи,
   Оператор    ◄───►│   + aiohttp webhook     │      демо, тикеты,
   (чат поддержки)  └────────┬──────────▲─────┘      события/аналитика)
                             │          │
              HTTP (issue)   ▼          │  webhook (user-registered)
                    ┌─────────────────────────┐
                    │  Grammerce Platform     │
                    │  grammerce.io           │  ← выдаёт одноразовые ссылки
                    │  /api/auth/telegram/... │     авторизации; уведомляет
                    └─────────────────────────┘     бот о новой регистрации
```

1. **Telegram (пользователи)** — основной канал общения, long polling.
2. **Telegram (чат поддержки / оператор)** — пересылка тикетов и живой чат.
3. **PostgreSQL** — хранение пользователей, UTM, демо-просмотров, тикетов и всех
   событий воронки.
4. **Платформа Grammerce** (`grammerce.io`) — выдаёт одноразовые ссылки входа по
   защищённому API (общий секретный ключ).
5. **Демо-боты** (`@grammerce_*_bot`) — отдельные Telegram-боты-витрины, на которые
   бот лишь даёт ссылки.

## Что бот собирает в аналитику

Каждое значимое действие пишется в таблицу событий (`bot_events`):
- `language_select` — выбор языка
- `menu_view` — открытие раздела меню (demo / support и т.д.)
- `demo_view` — просмотр конкретной ниши демо
- `register_click` / `register_error` — клик по регистрации / ошибка
- `support_faq` — открытие FAQ-вопроса
- `support_ticket` — создание тикета

Плюс UTM-метки (источник/кампания рекламы) сохраняются у каждого пользователя —
это позволяет оценивать, какая реклама приводит платящих клиентов.

---

## Коротко, одним абзацем

Grammerce Bot — это двуязычная Telegram-воронка продаж: она встречает пользователя
из рекламы, сохраняет источник трафика, показывает демо-магазины и ответы на частые
вопросы, по запросу соединяет с живым оператором через чат поддержки, а
заинтересованного пользователя доводит до входа на платформу через одноразовую
ссылку авторизации. Всё взаимодействие логируется в PostgreSQL для аналитики
эффективности рекламы и воронки.
